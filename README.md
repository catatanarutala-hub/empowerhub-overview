# EmpowerHub (prototipe)

Platform belajar online untuk perempuan, dibuat dengan React 19, Vite 6, dan Tailwind CSS v4.

## Menjalankan
```
npm install
npm run dev
```
Butuh Node 20.19 atau lebih baru.

## Deploy ke Vercel
Hubungkan repositori GitHub, Vercel membaca `vercel.json` (framework Vite, output `dist`). Pastikan folder `src` ikut terunggah.

## Dokumen Panduan
Tautan "Dokumen Panduan" ada di footer. Isinya mengikuti kode di `src/components/BrainstormingStudio.tsx`.
